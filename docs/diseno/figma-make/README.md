# Diseño de pantallas (Figma Make)

Fuente oficial del diseño visual de las 12 pantallas (P01–P12).

- `diseno-pantallas-web.make`: exportación original de Figma Make.
- `App.tsx`, `index.css`: código del diseño (React + Tailwind) extraído de la exportación.
- `capturas/`: cada pantalla renderizada a 1366 px y 360 px.

La paleta y las medidas están resumidas en `docs/diseno/tokens.css`, que usan el prototipo y el frontend.
