# Cuestionario de usabilidad para participantes

## Mensaje listo para compartir

Hola. Estamos evaluando la Mesa de Servicios Universitarios y necesitamos tu ayuda.
La actividad toma unos 15 minutos. Se evalúa la aplicación; no hay respuestas correctas
o incorrectas y puedes dejar la actividad cuando lo desees.

1. Recibe del facilitador tu identificador (P01, P02, P03, P04 o P05) y el acceso de prueba por privado.
2. Abre <https://msu-157-137-206-147.sslip.io> desde tu teléfono o computadora.
3. Realiza estas tareas sin que te indiquen dónde pulsar: inicia sesión, registra una
   solicitud sobre un proyector que no enciende, localiza su código y estado, abre su
   detalle, agrega un comentario y una imagen ficticia, consulta las notificaciones y sal.
   Usa el identificador asignado en el título del caso y evita datos personales.
4. Desde el mismo dispositivo y navegador, responde
   <https://msu-157-137-206-147.sslip.io/sus/> después de probar la aplicación.
5. Pulsa **Descargar mi respuesta CSV** y envía ese archivo al facilitador por privado.
   La página descarga tu respuesta en tu equipo; no la envía automáticamente.

Si algo te impide completar una tarea, descríbelo y continúa con lo que puedas.
No compartas contraseñas, correos personales ni capturas con información sensible.

## Versión escrita del cuestionario

Puede copiarse a un formulario externo o responderse por escrito si la descarga no
funciona. El facilitador registra después las respuestas en el formato del protocolo.
No mezclar las respuestas escritas con el CSV de la misma persona: cada participante
aporta una sola respuesta final.

- Identificador asignado: __________
- Fecha de la sesión: __________
- Rol probado: Solicitante / Supervisor / Técnico / Administrador.
- Dispositivo y navegador usados: __________
- ¿Probaste la aplicación antes de responder?: Sí / No. Si respondes No, realiza las tareas primero.

Marca una opción por afirmación:
**1 = Totalmente en desacuerdo; 2 = En desacuerdo; 3 = Neutral;
4 = De acuerdo; 5 = Totalmente de acuerdo.**

| N.º | Afirmación | Respuesta (1–5) |
|---|---|---|
| 1 | Creo que me gustaría utilizar este sistema con frecuencia. | |
| 2 | Encontré el sistema innecesariamente complejo. | |
| 3 | Pensé que el sistema era fácil de usar. | |
| 4 | Creo que necesitaría ayuda de una persona con conocimientos técnicos para utilizarlo. | |
| 5 | Encontré que las distintas funciones del sistema estaban bien integradas. | |
| 6 | Pensé que había demasiadas inconsistencias en el sistema. | |
| 7 | Imagino que la mayoría de las personas aprenderían a utilizarlo rápidamente. | |
| 8 | Encontré el sistema muy complicado de utilizar. | |
| 9 | Me sentí muy seguro/a utilizando el sistema. | |
| 10 | Necesité aprender muchas cosas antes de poder utilizar el sistema. | |

¿Qué fue difícil o qué mejorarías? ___________________________________________

Los diez ítems miden la facilidad de uso del sistema completo. La encuesta de nota
1–5 que aparece al cerrar una solicitud evalúa la atención de ese caso y es diferente.

## Para el facilitador

Asignar un identificador distinto a cada persona, facilitar cuentas de prueba y
registrar tareas, ayuda, tiempos, dispositivo y versión desplegada según el
[protocolo](Protocolo_SUS.md). No enviar la misma cuenta a varias sesiones simultáneas.
El reparto permite unas cinco personas; no exige que cada una tenga un rol distinto.
Pueden participar cinco solicitantes y añadirse sesiones de otros roles si están disponibles.

La versión web registra automáticamente el ancho observado y la fecha de Lima,
además de la marca UTC. Si se responde por escrito o mediante un formulario externo,
registrar esos datos en la ficha de sesión antes de transformar las respuestas a CSV.
No calcular ni informar una media hasta disponer de respuestas reales completas.
